# CONV: MOBILE_DEV | Explaining Kotlin coroutines to the team
APP: Javier, can you explain how we should use coroutines in the project?
YOU: Sure. Coroutines let us run code in the background without blocking the main thread.
APP: When should we use viewModelScope versus lifecycleScope?
YOU: Use viewModelScope in ViewModels for data operations. Use lifecycleScope in activities and fragments for UI-related work.
APP: What about withContext and Dispatchers?
YOU: Use Dispatchers.IO for network and database calls. Use Dispatchers.Main to update the UI.
APP: And how do we handle errors in coroutines?
YOU: Use try-catch blocks inside the coroutine or use a CoroutineExceptionHandler for global error handling.
